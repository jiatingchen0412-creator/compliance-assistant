# 01 · 需求规格说明

> 这份文档回答"这个软件到底要做什么"。任何新需求进来，先在这里登记，再决定做不做。

---

## 一、一句话定位

**一个装在中小企业老板自己 Windows 电脑上的合规自查助手。**
用大白话描述自己的系统情况，它从等保2.0、NIST CSF 2.0、OWASP Top 10 2021 里找出对应条款回给你，带条款编号和原文；涉及数据加密、访问控制、个人信息保护时用 ⚠️ 标出来。

---

## 二、目标用户

| 维度 | 描述 |
|---|---|
| 是谁 | 中小企业经营者、行政/IT 兼职负责人 |
| 技术水平 | **不懂技术**。不知道"身份鉴别"是什么，但知道"我们十几个人共用一个账号" |
| 他关心什么 | "我这样做有没有问题""会不会被罚""要改什么" |
| 他怕什么 | 被 AI 忽悠（编造条款号）、看不懂专业术语、操作太复杂 |
| 使用场景 | 等保测评前的自查、客户要求提供安全说明、出了安全事件后想知道该做什么 |

**明确不是给谁用的**：安全工程师、测评机构专业人员。他们需要的是完整标准文本和测评工具，不是这个。

## 三、功能需求

### A. 核心问答

| 编号 | 需求 | 验收标准 | 状态 |
|---|---|---|---|
| A1 | 自然语言提问，不需要懂术语 | 用口语描述能搜到对应条款，例如"员工共用一个管理员账号"能命中"身份鉴别" | ✅ |
| A2 | 基于三套标准回答 | 等保2.0（GB/T 22239-2019 安全通用要求）、NIST CSF 2.0、OWASP Top 10 2021 | ✅ |
| A3 | 必须带引用来源和条款编号 | 每条结论挂着可展开的引用卡片，显示：标准名 · 条款编号 · 标题 · 正文 | ✅ |
| A4 | 知识库没有就直说 | 明确回答"知识库中未找到"，并建议咨询专业安全顾问；**严禁编造条款号** | ✅ |
| A5 | 高风险项 ⚠️ 标注 | 数据加密 / 访问控制 / 个人信息保护三类必须标注 | ✅ |
| A6 | 信息不足先追问 | 描述太笼统时先问 1-3 个具体问题，**但不说"找不到"** | ✅ |

### B. 界面

| 编号 | 需求 | 验收标准 | 状态 |
|---|---|---|---|
| B1 | 打开浏览器就能用 | 双击 `启动助手.bat` 自动打开 `http://127.0.0.1:8765` | ✅ |
| B2 | 聊天界面 | 有打字机效果、回车发送、历史会话侧栏 | ✅ |
| B3 | 引用可展开 | 点一下展开原文，再点收起 | ✅ |
| B4 | 风险提示醒目 | 答案顶部黄色 ⚠️ 区块，写明为什么算高风险 | ✅ |
| B5 | 淡蓝色主色调、简洁直观 | 主色 `#2b7fd4`；零外部 CDN 依赖（断网也正常显示） | ✅ |
| B6 | 知识库管理 | 看得到已加载哪些条款：目录树、统计、搜索、筛选、导入、删除 | ✅ |

### C. 可靠性（用户没说，但必须有）

| 编号 | 需求 | 验收标准 | 状态 |
|---|---|---|---|
| C1 | 没有大模型也能用 | 自动降级为纯条款检索，照样给编号和原文，不白屏 | ✅ |
| C2 | 防幻觉硬约束 | 服务端校验引用白名单，不在检索结果里的条款号一律剔除 | ✅ |
| C3 | 会话历史 | 存本地，可回看、删除、导出 Markdown | ✅ |
| C4 | 免责声明 | 首屏、每条答案、导出记录里都有 | ✅ |
| C5 | 快捷问题入口 | 首页 8 个常见问题一键提问 | ✅ |
| C6 | 完全本机运行 | 除问题本身送给本地大模型外，不上传任何数据 | ✅ |

## 五、明确不做（v1 范围外）

| 不做的事 | 原因 |
|---|---|
| 多用户 / 登录体系 | 单机单人用，加登录只增加复杂度 |
| 自动扫描用户系统 | 只做"问答 + 条款匹配"，不联网探测 |
| 正式等保测评打分 / 出证 | 那需要资质，本工具是辅助自查 |
| 手机端适配 | 电脑上用的工具，窗口 ≥ 1000px |
| 打包标准原文进软件 | 等保2.0 是付费国标，有版权。详见 04 号文档 |

## 六、三条不能退让的底线

### 底线1 · 不许编造条款号

这是产品的生命线。用户是**拿这个去指导合规决策**的，
一个假的条款号可能让他在测评中直接不通过，或者误以为某项要求不存在。

**技术保障**（不能只靠提示词，见 05 号文档）：
① 检索层阈值兜底 → ② 提示词强约束 → ③ 服务端引用白名单校验 → ④ 正文编号扫描

### 底线2 · 高风险必须提示到位

数据加密、访问控制、个人信息保护这三类，一旦出问题就是**行政处罚或民事赔偿**级别。
宁可多提示，不能漏提示。

但同时**不能滥标**——三类风险全标的结果就是用户根本不看，
所以要求每条标注都必须有证据（问题关键词 / 引用条款标签 / 有文本佐证的模型判断）。

### 底线3 · 说清责任边界

首屏、每条答案、每份导出记录都必须写明：
> 本工具用于辅助自查，不构成正式测评结论，也不构成法律意见。

涉及高风险事项时，必须建议咨询专业安全顾问或律师。

三个问题有一个答不上来，就先别做。
