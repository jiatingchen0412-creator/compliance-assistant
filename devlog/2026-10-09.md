## 问题与决策
- 19:02 用 gh 的设备码授权而不是自己拿 token：用户点一次浏览器授权就行，我不需要接触任何账号密码或令牌
- 19:02 仓库里不放 app.db：它含真实问答历史，一旦推上去别人能看到，且 git 历史删不掉。宁可让用户重新生成
- 19:02 .gitattributes 里给 *.bat 单独指定 eol=crlf：cmd.exe 对 LF 结尾的批处理文件处理不可靠
- 19:02 winget 装 gh 会弹 UAC 提权、无人应答就卡住，改成从 GitHub Releases 下 zip 解压到 %LOCALAPPDATA%\Programs\gh，全程不需要管理员权限
- 19:02 仓库里不放 .env，但必须保证别人 clone 下来能自动生成：所以补的是 first_run.py 而不是把 .env 传上去
- 19:22 README 截图不能用真实数据截图：原来的截图侧栏里有用户问过的真实问题，发到公开仓库等于公开用户历史。改成从真实库里挑『问题本身就是界面内置快捷提问』的 4 条问答建临时演示库再截图
- 19:22 chrome --screenshot 的 --virtual-time-budget 不吃网络请求，接口没回来预算就用完，反复截到空状态。给 tools/cdp_eval.js 加 --pre（导航后先跑一段交互脚本）与 --screenshot（--settle 用真实时间，再用 Page.captureScreenshot 落盘）
- 19:22 test_frontend.py 的就绪探针不能用 urllib：本机装了代理 127.0.0.1:7897，回环地址也会被送去代理；而且服务还没 accept 时就一个劲重试会把它卡死 50 秒以上（实测等 6 秒再问第一次就 200）。改成 http.client + 先 sleep 3 秒，超时放宽到 60 秒
- 19:30 把 gh 加进用户级 PATH（追加到 HKCU\Environment 的 Path 末尾，原值是 REG_SZ 不含 %变量%，直接追加安全）。只对新开的终端生效，当前窗口仍要用全路径
- 20:44 CI 后端跑两个平台：Windows 才是主要目标平台（用户双击 .bat 启动），ubuntu 只是快；两个都跑信号最全
